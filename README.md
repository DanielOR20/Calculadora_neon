# Neon Calculator 🌆➗

Calculadora interactiva con estética cyberpunk/neón, construida con HTML, CSS y JavaScript vanilla.

## Funcionalidades
- Operaciones básicas: suma, resta, multiplicación, división, porcentaje.
- Historial de las últimas 5 operaciones.
- Efecto glitch visual al ocurrir un error (ej. división entre cero).
- Soporte completo de teclado (números, Enter, Backspace, Escape).
- Diseño responsive para dispositivos móviles.
- Estética neón con animaciones al interactuar con los botones.

## Cómo correrlo localmente
```bash
npm install
npm run dev
```

## Tecnologías
HTML5, CSS3, JavaScript (vanilla), live-server.
